# AX1OM Network

**为多条线路建立清晰秩序。**

AX1OM 组织自用并开源的原生 macOS 代理编排客户端。

SwiftUI / AppKit · Mihomo · Provider · TUN

[下载预发布版本](https://github.com/luolisen/ax1om-proxy/releases) · [架构](docs/ARCHITECTURE.md) · [迁移与回退](docs/MIGRATION.md)

</div>

## 为什么做 AX1OM Network

机场订阅、自建专线和实验节点可以同时存在，但不必承担同一种任务。AX1OM Network 把节点来源、业务策略和实际连接分开管理：订阅更新节点，策略决定出口，连接页面展示流量实际去了哪里。

这是我们为自己的日常网络维护开发的工具，也欢迎有相似需求的人使用、检查和改进。它是代理客户端与编排工具，不提供机场服务、节点套餐或订阅资源。

## 功能

| 页面 | 作用 |
| --- | --- |
| 控制台 | 连接状态、实时流向、粒子动画和可选择周期的流量统计 |
| 用量 | 上传与下载、趋势、热力图；日期明细、业务 / 节点用量切换 |
| 订阅 | HTTP / 本地来源并存；有效套餐额度显示进度，节点用量单独统计 |
| 节点 | 策略组、节点选择、协议、UDP 与历史延迟 |
| 编排 | AI、Google、办公、社交、流媒体、国内应用与默认出口分别管理 |
| 连接 | 搜索、业务颜色、实际链路与终结单个连接 |
| IP 检测 | 实际请求出口、第三方 IP 信息、HTTPS 响应、DNS 记录与当前节点 |
| 设置 | 外观、动画、统计周期和独立核心控制 |

界面使用原生 SwiftUI / AppKit，不使用 Electron。发行包内置 Mihomo、Node.js 和 YAML 解析器；日常运行不需要安装 Clash Verge、旧版专线面板或全局 Node.js。已有 Clash Verge 配置可作为一次性迁移来源。

## Provider 与编排

多份订阅以独立 Provider 同时加载。选择业务组中的节点，无需在整份订阅配置之间切换；更新一个 Provider 不需要重启核心。

业务组可以使用固定出口、人工选择或有顺序的主备线路。国内应用、局域网和 Tailscale 有独立直连规则，YouTube、推送服务等具体规则优先于宽泛分类。自建专线是可选资源，认证信息只保存在本机。

Provider 更新不会主动要求重启核心，但它不能保证现有连接永远不断：节点被删除、认证变更、线路故障、手动更换出口或切换 TUN 都可能使连接需要重建。主备健康检查也不能代替业务登录、会话与长连接验证。

## 安装与首次使用

1. 从 [Releases](https://github.com/luolisen/ax1om-proxy/releases) 下载适合 Apple Silicon 的应用包，解压后放入“应用程序”。
2. 添加自己的 HTTP 或本地 Mihomo YAML 来源，或导入已有 Clash Verge 的缓存；检查业务组与节点。
3. 在设置中点击“生成配置”，关闭 TUN 开关后使用“启动独立代理”先测试。
4. 准备替换旧代理时，按 [迁移说明](docs/MIGRATION.md) 关闭旧 TUN 和旧核心，再打开 TUN 开关，点击“启动 TUN”并完成管理员授权。

默认生成的正式配置启用 TUN；独立代理模式单独禁用 TUN，在 `127.0.0.1:17901` 提供 HTTP / SOCKS 入口，需要应用显式使用，不自动切换系统代理或修改默认路由。正式 TUN 配置的本机混合端口为 `18081`，DNS 端口为 `18082`。管理员授权通过原生 macOS Authorization Services 发起，应用不会要求把密码写入配置或聊天。

**v0.1.0 是首个预发布版本。** 当前发行包使用临时签名，尚无 Developer ID 签名或 Apple 公证。系统可能阻止首次打开；请按照 macOS“隐私与安全性”中的提示检查来源并允许打开，不需要关闭系统整体安全保护。当前尚未完成真实环境 TUN 接管与长期稳定性验收，建议先保留原客户端与配置，以便回退。

## 数据与隐私

- 用户数据位于 `~/Library/Application Support/AX1OM/`，目录权限 `0700`，敏感配置权限 `0600`。
- 订阅 URL、节点认证和控制接口密钥不进入公开仓库，也不出现在脱敏状态展示中。
- 用量来自核心累计字节和连接差量，不是服务商账单或所有网卡总流量；未采集的历史不补估算。节点统计只按实际连接链路中可确认的出口归属，不回填应用未运行期间的数据，无法归属的字节单列。
- 订阅套餐额度来自有效订阅元数据；本机节点用量是独立的采样记录。两者可能不同，不能把本机统计当成服务商实时扣费。
- IP 检测在手动触发时访问检测站点。第三方评分只是参考，不代表服务提供商的官方判断；没有实际结果的检测项目不展示。
- DNS 配置、DNS 查询结果和浏览器泄漏实测是不同证据。本项目不承诺匿名性、账号安全或“防封号”。

请勿把自己的 `sources/`、`runtime/`、候选配置、订阅地址或原始日志上传到公开 Issue。

## 从源码构建

需要 macOS 14 或更高版本、Apple Silicon、Xcode 命令行工具，以及 Python 3。源码开发和测试需要 Node.js；完整应用包会自带运行组件。

```sh
python3 scripts/fetch-runtime.py
python3 package-app.py
```

构建产物位于 `dist/AX1OM Network.app`。运行组件从官方发布来源获取，版本与校验逻辑见获取脚本；依赖及许可证见 [NOTICE.md](NOTICE.md)。

```sh
swift test
node --test Tests/*.test.cjs Tests/Bridge/*.test.cjs
```

测试覆盖采样与统计、规则编排、Provider 存储、独立控制接口、单连接终结及检测结果解析。软件测试通过不等于真实 TUN、每个机场节点或所有业务已验收。
